# Grizzly Contacts

> A secure, offline-first Progressive Web App (PWA) contact manager designed with a sleek, battery-saving dark UI. Built to match the aesthetic and robust architecture of the Loonie Tunes ecosystem, Grizzly Contacts provides granular privacy controls, custom group management, and seamless offline data synchronization.

---

## ✨ Key Features

* **🎨 Sleek Dark & Black Aesthetic**: Optimized with custom themes (Pure Black, Dark, Light) and vibrant accent color pickers.
* **🔒 PIN-Protected Private Contacts**: Tap the app logo 3 times to access a hidden, PIN-locked address book for sensitive contacts.
* **📂 Advanced Group Management**: Organize contacts into custom groups, with granular toggles to permit or block 3rd-party sync/sharing (e.g., restricting Telegram or Facebook access for private entries like mechanics or dentists).
* **🔍 Smart Duplicate Finder**: Automatically scans names, phone numbers, and email addresses to detect duplicates and lets you safely merge or remove them.
* **♻️ 30-Day Recycle Bin**: Deleted contacts are safely stored in a rolling 30-day recycle bin before permanent deletion, with instant restore options.
* **☁️ Cloud Webhook Backups**: Automatically syncs and backs up your complete address book as structured spreadsheet/XLSX data to your custom cloud endpoint whenever changes occur.
* **📥 Safe Import & Export**: Export your entire database to JSON or use safe import checking to prevent duplicate additions.
* **📱 PWA & Offline-First**: Fully responsive with offline service worker caching and native-like standalone app installation.

---

## 🚀 Quick Start / Deployment

1. Clone or download the repository files (`index.html`, `manifest.json`, and `sw.js`).
2. Add your custom icons (`icon.png` and `small-icon.png`) to the root directory.
3. Host the files on any static hosting provider (GitHub Pages, Netlify, Vercel) or run locally using a local development server.
